## Projects

### 🌱 Botanic — Plant E-Commerce Platform
> Full-stack web application for plant sales with authentication, cart system, and backend logic.

- Built with **React + Flask + MariaDB** REST API architecture
- Achieved **40% faster page load times** through optimized API and query design

---

### 🔐 Broadcast Encryption System — Cryptographic Key Management
> Secure transmission system that delivers encrypted content to authorized receiver subsets.

- Implemented **hierarchical key management** with forward secrecy and dynamic group membership
- Built **key revocation and re-keying mechanisms** — excluded users cannot decrypt future content
- Validates against multi-user access control scenarios using asymmetric cryptographic primitives

---

### 🧹 WipeForge — Linux Secure Data Wiping Utility
> Linux-based secure file deletion tool that prevents forensic data recovery.

- Implements **DoD 5220.22-M standard** multi-pass overwrite algorithms
- Interactive **TUI interface** for file, directory, and full-disk sanitization
- Post-wipe cryptographic verification with audit-ready session logs
- Prepared **PKGBUILD for AUR distribution**

---

### 🤖 Tarz — Personal AI Assistant
> Offline-first, JARVIS-style AI assistant with system-level access and modular plugin architecture.

- Voice-activated with **local LLM integration** — no cloud dependency
- Hybrid intelligence pipeline: local inference + internet fallback
- Executes **system-level commands** (app automation, file management) via voice
- Designed with extensible plugin architecture for workflow automation

---

### 🧑‍💻 FaceDesk — Face Recognition Attendance System
> Automated attendance tracking using computer vision and a local database backend.

- Real-time face detection and identity verification using **Python + OpenCV**
- **95% recognition accuracy** — reduces manual attendance entry time by **70%**
- Flask REST API backend with **MariaDB** for persistent attendance records
